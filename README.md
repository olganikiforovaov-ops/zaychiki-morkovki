# Зайчики и морковки

Небольшая игра для тренировки состава числа до 10.

Игра помогает ребенку отрабатывать:
- сложение до 6, 7, 8, 9;
- вычитание в пределах 10;
- задания с пропуском;
- более сложные задания с двумя действиями.

## Как открыть

Откройте файл `index.html` в браузере.

## Как менять игру

Все находится в одном файле `index.html`.

Что чаще всего менять:
- название игры: текст внутри `<h1>...</h1>`;
- числа для тренировки: массив `goals`;
- уровни сложности: массив `levels`;
- внешний вид: стили внутри блока `<style>`.

## Как выложить через GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `zaychiki-morkovki`.
2. Загрузите туда файлы `index.html` и `README.md`.
3. Откройте `Settings` -> `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/root`.
6. Нажмите `Save`.

Через пару минут GitHub покажет ссылку на игру.

## Важно про приватность

В публичной версии используется нейтральное название без имени ребенка.
